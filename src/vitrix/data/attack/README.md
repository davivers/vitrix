# ATT&CK Enterprise catalogue

`enterprise.json` is a compact extract (tactics and non-revoked, non-deprecated techniques and
sub-techniques: id, name, tactics, parent) of MITRE's Enterprise ATT&CK STIX data.
Refresh it with `python scripts/update_attack_catalog.py`.

See `NOTICE` below.
